# HomeAssistantPlugin
The HomeAssistantPlugin enables control over Home Assistant entities within the Sepian workspace.

### Commands
* `list_entities`: Lists all entities in Home Assistant.
* `find_entity`: Finds an entity by its ID or name.
* `get_state`: Gets the state of an entity.
* `turn_on`: Turns on a device.
* `turn_off`: Turns off a device.
* `toggle`: Toggles a device's state.

### Usage
To use the HomeAssistantPlugin, simply call the desired command with the relevant arguments. For example:
* To list all entities in Home Assistant, call `list_entities`.
