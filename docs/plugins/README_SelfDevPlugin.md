# SelfDevPlugin
The SelfDevPlugin is a powerful tool for developers working within the Sepian workspace. It provides functionality for reading, searching, proposing edits, and running tests on files.

### Commands
* `list_files`: Lists all files in the Sepian workspace.
* `read_file`: Reads the contents of a file.
* `search_code`: Searches for specific code within files.
* `propose_edit`: Proposes an edit to an existing file or creates a new file.
* `run_test`: Runs a test on a file.

### Usage
To use the SelfDevPlugin, simply call the desired command with the relevant arguments. For example:
* To list all files in the Sepian workspace, call `list_files`.
